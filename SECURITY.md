# Security policy

Report suspected vulnerabilities through [GitHub private vulnerability reporting](https://github.com/kidrainzboy/WallShift/security/advisories/new). Use the public issue tracker for regular bugs and feature requests.

Include the affected WallShift version and Windows build, the impact, and the steps to reproduce. Use non-sensitive sample media. Keep vulnerability details in the private report while the maintainers investigate.

Fixes target the latest stable release.
