# Contributing to WallShift

Bug reports, translations, and pull requests are welcome.

## Report a bug

Use the [bug report form](https://github.com/kidrainzboy/WallShift/issues/new?template=bug-report.yml). Include the WallShift version, Windows build, display arrangement and scaling, and steps to reproduce. For video issues, include the container and codec. Use a non-sensitive sample if you share a screenshot or test file.

## Send a change

1. Fork the repository and create a branch from `main`.
2. Make a focused change. Keep English and Vietnamese strings aligned when changing text in `src/strings.hpp`.
3. Follow the [Windows build instructions](README.md#build-from-source). Run the resulting executable and check the behavior you changed.
4. Open a pull request and describe the problem, what changed, and how you verified it. Screenshots are helpful for widget or menu changes.

Do not commit generated build output, user settings, or personal wallpapers. Contributions are submitted under the [MIT License](LICENSE).
